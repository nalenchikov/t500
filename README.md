# T500 — интерактивная модель TANK 500

Программа для macOS (Apple M1 и новее) и Windows 10/11. Внутри — 3D-модель GWM TANK 500 3.0T, в которой каждая деталь
отдельный объект с номером из каталога.

## Что умеет

- **Каталог деталей** — поиск по названию или номеру, карточка детали, показ одной детали.
- **Механизмы** — двигатель, коробка 9AT с подсветкой включённых муфт, раздатка, мосты, подвеска и рулевое; двери,
  капот, багажник, стёкла и люк открываются.
- **Группы, разрез, взрыв-схема** — заглянуть внутрь машины и разобрать её на узлы.
- **Как работает** — двигатель, коробка, раздатка, мост с блокировкой и подвески по отдельности: такты, искра, поток
  воздуха, муфты, дифференциал. Уроки по шагам и проверка себя.
- **ТО** — что менять на каждом пробеге по графику из руководства по эксплуатации, с номерами деталей.
- **Тюнинг** — диски R17–R20, размеры шин и лифт 1″ / 2″: диаметр, спидометр, клиренс, запаска, советы владельцев.
- **Полигон** — езда со своей физикой подвески и трансмиссии: подъёмы, бугры, брёвна, лёд и грязь.

## Скачать и запустить

Файлы — в разделе [Releases](https://github.com/nalenchikov/t500/releases/latest): `T500-mac.zip` или `T500-win.zip`.
В архиве лежит «Как запустить.txt».

- **macOS:** перенесите T500 в «Программы». Программа не подписана сертификатом Apple, поэтому при первом запуске
  откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- **Windows:** распакуйте в свою папку (не в Program Files) и запустите `T500.exe`. Если появится «Windows защитила
  ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».

Когда выходит новая версия, программа сама предлагает обновиться (кнопка в верхней строке).

## Важно

Справочная модель, не материал GWM. Номера деталей, размеры, объёмы и интервалы могут отличаться от вашего
автомобиля, сверяйте с официальными источниками. Ответственности за использование сведений не несём.
TANK и GWM — товарные знаки Great Wall Motors.
